# Optional Integrations

These are adapters only and are not core dependencies:

- corporate SMTP or local mail relay;
- Outlook/Google Calendar synchronization;
- a real ERP API;
- manually sourced public market research;
- external customer email delivery.

ABP continues to operate without every item above. If an adapter is absent or unavailable, local PDF download, internal messages, notification center, CRM calendar, imports, analytics and LAN portal operation remain available. No API key, cloud account or paid quota is required for core operation.
