# Application Workflow Services

API commands validate permission, DENY, Country Scope, state, row version and idempotency before recording a short transaction. Explicit worker handlers perform the mapped asynchronous responsibilities.

# Worker Architecture

The PostgreSQL worker claims only registered event/job types with leases. It records terminal results or safe retryable/permanent failure codes.

# Transaction Boundaries

Business state, immutable audit and new outbox messages are committed in the same transaction. Network/render/file I/O is outside long database locks and finalization rechecks frozen state.

# Outbox

Every mapped request event is handled idempotently. Domain completion events are inserted transactionally.

# Durable Jobs

Registered handlers cover every mapped job type, including the Step-7 combined official-document/send compatibility type.

# Idempotency

Unique job/event keys, deterministic PDF storage identity and conditional terminal updates prevent duplicate effects.

# Concurrency

rowVersion/input/content hashes, serializable return submission and conditional updates reject stale work.

# Crash Recovery

Expired leases are reclaimable. Artifact creation is deterministic and terminal DB transactions are replay-safe.

# Retry / Failure Model

Transient failures retry with bounded backoff; permanent malware, stale hash and missing provider states persist safe codes and never fabricate completion.

# Authorization

Authorization remains at API entry and actor/scope context is persisted in job source, audit and captured filters.

# Country Scope

Country Scope is applied before ownership/share. Export generation intersects captured scope with the requester’s current active scope.

# Audit

Every terminal workflow effect records immutable audit evidence.

# Correlation / Traceability

traceId, correlationId, jobId, source type/id, content hashes and document hashes link request to result.

# Quotation Approval

Manager routing, self-approval denial, exact material snapshot and invalidation remain enforced by the API workflow.

# Official PDF

Playwright 1.55 with pinned Chromium renders an actual server-side PDF from authoritative quotation data. Metadata, SHA-256 and official relation are persisted only after the artifact is verified.

# Send / SENT

Without a configured provider, only the locked Manual/External branch can finalize SENT. It stores user-confirmed evidence and labels delivery UNVERIFIED.

# ERP Import

Validation, commit, retry and eligible rollback have explicit handlers; commit is atomic and duplicate-safe.

# ERP DQ / DATA_CONFLICT

Open BLOCKER/ERROR issues prevent commit. Fuzzy matching is never performed by the worker.

# ERP Reconciliation

Reconciliation is read/compare by default and stores a completed summary without mutating canonical facts.

# Returned Scrap

Submission uses serializable locking and cumulative original-line eligibility, preserves the 25% snapshot and requires manager approval before finalization.

# Other Handoff Workflows

Logistics frozen-input handling, local governed exports, malware scan and user-invite provider boundary are explicit.
