# Dependency Security Audit

Status date: 2026-09-09. The self-hosted production runtime consists of the API, web bundle, worker, PostgreSQL and Caddy. `apps/mobile` is not built into or shipped with that runtime.

The current dependency proof passes. Workspace overrides pin the patched transitive versions used by the release tree: `multer@2.3.0`, `js-yaml@3.15.2` and `4.3.2`, and `@xmldom/xmldom@0.8.15`. The API build and the 22 web tests passed after the lockfile was regenerated.

| Package                 | Severity                | Dependency chain                                                                               | Production runtime                       | Exploitability in ABP self-hosted runtime                                                                           | Disposition                                                                     |
| ----------------------- | ----------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `image-size@1.2.1`      | High                    | Every reported path starts in `apps/mobile`, enters `react-native`, then Metro or Metro Config | No                                       | The vulnerable ICNS/JXL/HEIF parsers are absent from the API, web and worker containers                             | Track upstream React Native/Metro update; accepted for this on-prem web release |
| `@babel/runtime`        | Moderate                | Transitive build/runtime dependency                                                            | Mixed                                    | No demonstrated ABP input reaches the named-capture-group transpilation pattern                                     | Track and update with the owning framework                                      |
| `uuid`                  | Moderate                | Transitive                                                                                     | Mixed                                    | ABP does not pass attacker-controlled buffers to UUID v3/v5/v6 APIs                                                 | Track upstream resolution                                                       |
| `postcss`               | Moderate                | Frontend build chain                                                                           | Build only                               | Production serves prebuilt CSS; it does not process attacker-controlled source maps                                 | Track Vite/PostCSS update                                                       |
| `decode-uri-component`  | Moderate                | Transitive tooling                                                                             | No verified server path                  | No affected decoding endpoint was found in the self-hosted services                                                 | Track upstream resolution                                                       |
| `qs`                    | Moderate                | Express/transitive                                                                             | API runtime                              | Request limits and validation reduce exposure, but the dependency should be updated when Express resolves the chain | Tracked residual                                                                |
| `@xmldom/xmldom@0.8.15` | None currently reported | Expo/mobile XML tooling                                                                        | No                                       | The previously reported vulnerable transitive versions were replaced by the patched workspace override              | Remediated                                                                      |

| `multer@2.3.0`          | None currently reported | NestJS platform upload middleware                                                              | API runtime                              | The vulnerable runtime version was replaced and the API compiles against the resolved dependency                    | Remediated                                                                      |

The security proof rejects every Critical advisory. It also rejects every High advisory unless every reported dependency path is under `apps/mobile` and includes Metro. This keeps the production gate strict without treating unused mobile build tooling as part of the on-prem web runtime.
